Generated by `python -m patchsight.pipeline retrieval-report`; do not edit by hand.

When a fix's candidate functions do not fit the prompt's token budget, the extractor keeps them in BM25 order while they fit; a true vulnerable function that is cut cannot be picked by the model. On the reports whose prompts are cut, this counts the true vulnerable functions among the candidates that each order keeps, with the extractor's own token costs (ADR 0003). No model is called.
