## Limits of this check

- These are necessary conditions, not proof. A commit on the right repo that changes source may still be a refactor rather than the fix; that is measured against labelled data later.
- A package whose metadata names no GitHub repo and has no OSV GIT range lands in *repo not declared*, even when the candidate is correct.
