# Keyword-match baseline

Generated by `python -m patchsight.pipeline keyword-baseline`; do not edit by hand.

A changed function is marked vulnerable when the advisory's summary or details name it: its full name, or the part after its last dot, as a whole word, case-sensitively. This is the rule E10 declared before it was measured ([experiments](../experiments.md)); it is not tuned here. The candidates are ChangedFuncs' own, every function the fix changed after the path filter, and both are scored against the same labels. No model is called.
