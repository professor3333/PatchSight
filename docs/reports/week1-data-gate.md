## Gate result

**PASS.** Share of PyPI vulnerabilities with at least one GitHub fix link (commit, pull request or tag comparison): 67.5% (4,799 / 7,105; 95% CI 66.4% to 68.6%). Threshold: 40%. Below it, the fix-commit locator agent becomes essential (proposal §15).

This counts *candidate* links, so it is an upper bound. Only 22.3% (1,584 / 7,105; 95% CI 21.3% to 23.3%) carry an explicit fix signal (a FIX-typed reference or a GIT-range fixed commit); the rest are untyped links to commits or pull requests. How many candidates really are the fix is measured when the diffs are fetched.
